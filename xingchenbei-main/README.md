## 🎯 大赛介绍

大模型与生成式 AI 的爆发，让 **算力** 成为数字经济的「核心底座」。而 **算子**，正是连接算法模型与底层硬件的「最小计算单元」——它的性能与精度，直接决定了国产 AI 算力生态的上限 🚀

当前，国产算力生态正从「可用」迈向「好用」，这背后，亟需一批 **既懂算法、又懂硬件、更能写出高性能算子** 的复合型人才。

为此，**中电信人工智能（北京）科技有限公司携手华为、AtomGit** 共同发起本届挑战赛，以赛为媒，搭建面向全国高校学子的算子开发实战平台，推动 Ascend C 算子生态在高校的技术普及与人才储备 💡

**🏷️ 赛事主题：算子筑基，智惠未来**

- **「算子筑基」**：夯实国产 AI 算力底层根基，以算子开发为支点，撬动国产大模型训练与推理的整体效能；
- **「智惠未来」**：让 AI 算力真正普惠产业与人才，在实战比拼中发掘潜力青年，反哺国产算力生态。

🎁 赛事秉持 **「以赛代选、以赛代招」** 理念：获奖团队不止拿奖金，更直通主办方 **实习 & 校招面试**，让企业人才需求与高校培养高效对接！

## 📋 大赛规则

### 👥 1. 参赛说明

**参赛对象：** 面向全国高校全日制本科、硕士、博士研究生；每支队伍 **2–3 人**，须指定 1 名队长负责报名与作品提交。

**组队与报名：**

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 👫 组队规模 | 2–3 人/队，可跨年级、跨专业组队（建议同校组队）              |
| 💻 报名方式 | 通过 AtomGit 赛事平台在线报名，提交队伍信息与参赛协议        |
| ⏰ 报名须知 | 须在指定时间内完成报名、组队、作品提交方为有效参赛（每日最多提交 5 次，取最优成绩记录） |
| ⚖️ 公平参赛 | 各阶段赛后组委会将进行代码查验，发现重复或违规将直接取消资格与成绩 |

**📜 参赛纪律：** 作品须为原创，无抄袭、无第三方闭源依赖；获奖团队须签署代码开源授权并纳入开源社区资产；违规者取消成绩并追回奖励，情节严重者列入赛事黑名单。

### 🎯 晋级规则

- **初赛晋级：** 经评委团确认项目完整、正确达标且性能靠前的队伍晋级决赛。
- **决赛名次：** 按现场评分排序；同分时以初赛评分作为最终名次依据。
- **争议与申诉：** 建立评审申诉通道，48 小时内受理，3 个工作日内出具书面复核说明；采用「自动化查重 + 人工复核」，明确抄袭判定与处罚规则。

#### ✅ 作品有效性判定

一件有效参赛作品须同时满足：

- ✅ **环境运行合规：** 可在指定昇腾环境正常编译、运行，无编译错误或运行时崩溃
- ✅ **精度与性能达标：** 精度验证通过前提下，按性能耗时总和排名
- ✅ **代码合规规范：** 无抄袭、无第三方闭源依赖；规范清晰、可独立复现

#### 🔍 评审维度

| 评审维度               | 考察内容                     | 评测项                                             |
| ---------------------- | ---------------------------- | -------------------------------------------------- |
| ✅ 正确性（准入门槛）   | 算子计算结果与基准实现一致性 | 精度对比、边界覆盖、稳定性                         |
| ⚡ 性能（核心评分项）   | 算子执行效率                 | 耗时（ms）、吞吐量（TFLOPS/samples·s⁻¹）、资源占用 |
| 📝 文档与规范（仅决赛） | 代码工程质量与优化思路呈现   | 代码可读性、注释完整性、优化思路说明、复现友好度   |

#### ⚖️ 评审权重

| 维度       | 初赛权重         | 决赛权重         | 评分方                      |
| ---------- | ---------------- | ---------------- | --------------------------- |
| 正确性     | 必须满足基线要求 | 必须满足基线要求 | 自动化评测脚本 + 实时排行榜 |
| 性能       | 100%             | 80%              | 自动化评测脚本 + 实时排行榜 |
| 文档与规范 | —                | 20%              | 专家评审团人工评定          |
| 合计       | 100%             | 100%             | —                           |

> ⚠️ **无效作品判定：** 精度不达标、环境无法运行、存在抄袭或第三方闭源依赖、提交材料不完整者，均判为无效，不计入排名。

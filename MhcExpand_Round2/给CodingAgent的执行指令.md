## 四、第三步：按独立实验实施，不捆绑改动

### E1：Scalar/入口轻量化

依据 S04 检查 TPipe 是否位于计算类内部而妨碍别名分析；如需要，单独改成在入口构造再传给计算类。下一独立实验才调整按需初始化，让某模式只构造其所需 buffer/事件。保持 tiling、数值和事件含义不变。

随后可把方向/dtype/主要模式做编译期特化，再独立考虑 m=2/4/8 的短循环展开，保留 generic m。模板使用本地 8.5 已支持的定义，避免枚举所有 R×W×m 组合。公共 shape 计算可移到 Host tiling，数值计算不能移走；地址乘法保留必要的 64-bit 与溢出检查。

### E2：FP16 反向基础混合 Axpy

依据 S01/S03，尝试首流 Cast 到 float acc，后续 `Axpy(acc_float, x_half, half(1), count)`，最后沿用基线转换输出。目标是保留 FP32 累加，去掉后续流的独立 float temp Cast+Add；不是 Round 4 的 half 累加。

先核对本地头文件/生成代码/精度；保持 R6 tile、调度、k 顺序、事件边界不变。这里用基础 API，不误用带 sharedTmpBuffer 的高阶同名接口。BF16 不在该基础混合类型表中，保持原 Cast+Add，禁止 BF16→half 硬套。

第一版只验证算术替换；后续独立实验才用节省的 UB 扩 tile。API 调用数减少不等于硬件指令必然减少。不能放宽容差或改 golden 来通过。

### E3/E4：前后向各自的容量和任务模型

按实际活跃缓冲重新核算，并查询平台 AIV/UB，不写死核数/容量。参考布局仅作估算：前向两份 16-bit 输入约 4N 字节；反向双输入+float acc+float temp+16-bit 输出约 14N；Axpy 若去掉 temp 约 10N。实际额外 padding/队列/双输出/临时区必须计入。

单独试前向 N 上限 8192/16384/32768 等合法候选；反向另试 4096/8192/12288 等容量许可的候选。候选数字不是最优承诺，最终按通用规模/容量/并行度分派，保留 R6 小任务策略。

D=7168 时 R=1/2/4 是理解容量的公开例子，不准写成单一 shape 白名单。T=ceil(S/R)*ceil(D/W)，任务数/核数/每核循环数都记录。单任务核与多任务核的尾部分布必须正确。

### E5：任务分配单独实验

固定 tile/计算后，比较原跨步分配与每核连续区间。后者：q=T/C,r=T%C，count=q+(core<r)，start=core*q+min(core,r)。不预设连续一定更快，检查唯一覆盖和尾任务。

### E6：m 流分组预取

只有读命令/Scalar 成本有线索时才尝试。W=D 时把同 token 的 G 个连续流打包，读 `[R,G,D]` 后保持原 k 顺序累加。重新核算 G 倍输入缓冲；两个分组输入占 4GN 字节。G=2/4/m 和不足 G 尾组都要处理。

W<D 不沿用连续 G*D 块公式；G<m 时跨行间隔不同，不能强行一个二维 stride 表示。必要时维持分层循环或 fallback。不能为减少命令而引入更大 UB/更多向量碎片却不测。

### E7：同步/mask 等细节，逐项实验

每个事件必须对应 RAW/WAR/WAW 依赖。前向 input buffer 直到最后一份 MTE3 读取完成才可被下一次 MTE2 覆盖。反向各输入/temp/acc/output 分别画生命周期。先保证只有 1/2/3 tile 的序言尾声正确，再考虑减少冗余事件；不直接删除所有 barrier。

BF16 保留 FP32 Cast+Add，可根据实际热点试外部 mask 和循环展开。先检查当前 count API 是否已做优化；mixed-width stride、mask 粒度与模式恢复按实际接口处理。不要把 Cast/Add 当成两个独立可同时执行的硬件流水。

一次只改变一个机制；每次新 commit/patch 必须记录：父版本、待验证假设、适用域、预期影响、保持不变项、风险、测试状态、逐点原始时间、真实分数（可为空）、取舍结论。

数值覆盖 FP16/BF16、双向、m=1/2/3/4/5/7/8/9、S=1、D=1、16/32 字节边界、R/W±1、任务尾核和随机非对齐形状；选择成对覆盖而非全部笛卡尔积。使用独立 holdout。检查完整输出，不能只抽几项。

增加大值相消/大小值混合：如 FP16 [40000,40000,-40000,-40000]。FP32 加法也不能任意交换顺序；BF16 可表示的 [2^26,1,-2^26,1] 能检验不同归约树。特殊值范围/最终溢出按明确契约处理，不能私自变更参考语义。
